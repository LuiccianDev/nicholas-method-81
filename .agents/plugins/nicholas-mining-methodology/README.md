# Nicholas Mining Methodology Plugin

Plugin especializado para la selección numérica de métodos de explotación minera subterránea y a cielo abierto según la metodología de **David E. Nicholas (1981)** (*Method Selection: A Numerical Approach*).

## Contenido del Plugin
- **Skill:** `nicholas-methodology` — Procedimiento de evaluación geométrica y geomecánica, rangos de variables y reglas de desempate.
- **Rules:** Directrices estrictas para preservar la integridad de las matrices de puntuación, descarte de Open Pit en métodos subterráneos y determinismo en los cálculos.

## Métodos Evaluados
1. Open Pit (Cielo Abierto)
2. Block Caving
3. Sublevel Stoping
4. Sublevel Caving
5. Longwall Mining
6. Room and Pillar
7. Shrinkage Stoping
8. Cut and Fill Stoping
9. Top Slicing
10. Square Set Stoping

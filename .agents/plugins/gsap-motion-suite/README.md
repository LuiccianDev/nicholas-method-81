# GSAP & Motion Animation Suite

Suite unificada para animaciones web de alto rendimiento combinando **GSAP (GreenSock)** y **Motion**.

## Alcance
- Integración en componentes React 19 mediante el hook oficial `@gsap/react` (`useGSAP`).
- Efectos de scroll interactivos y parallax con `ScrollTrigger`.
- Transiciones declarativas y gestos mediante `motion/react`.
- Prevención de layout thrashing mediante transformaciones CSS aceleradas por GPU (`x`, `y`, `scale`, `rotation`, `opacity`).

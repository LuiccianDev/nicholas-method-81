# Astro Framework & Live Docs Plugin

Plugin dedicado exclusivamente a **Astro 7**, sus patrones de arquitectura, configuración SSR y consulta en tiempo real a la documentación oficial de Astro mediante Model Context Protocol (MCP).

## Capacidades
- **Conexión MCP a Documentación Oficial:** Integra el servidor remoto Streamable HTTP de Astro (`https://mcp.docs.astro.build/mcp`) para consultar sintaxis, integraciones y APIs actualizadas en vivo.
- **Skill:** `astro` — Procedimientos de configuración de SSR, islas de componentes (`client:*`), colecciones de contenido y adaptadores.
- **Rules:** Directrices para el stack del proyecto (Astro 7 con `@astrojs/vercel`, `output: 'server'` y middleware seguro).

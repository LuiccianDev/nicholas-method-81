# Astro & Tailwind Frontend Suite

Suite de diseño frontend adaptada al stack del proyectos:
- **Astro 7:** Renderizado híbrido server/SSR con islas de React 19 (`client:load`, `client:visible`).
- **Tailwind CSS v4:** Configuración CSS-first en `src/styles/index.css` con `@theme`.
- **Patrones de diseño:** Componentes modulares, tipografía estricta y diseño industrial adaptado a minería y geotecnia.

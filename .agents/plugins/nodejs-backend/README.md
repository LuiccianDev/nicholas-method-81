# Node.js & Backend Architecture

Plugin para el desarrollo de endpoints y middleware en backend:
- Manejo de endpoints en `src/pages/api/` (ejemplo: `chat.ts` con Gemini AI SDK `@google/genai`).
- Middleware de seguridad con headers HSTS, X-Content-Type-Options y CSP en `src/middleware.ts`.
- Patrones de resiliencia y límites de tamaño de payloads.

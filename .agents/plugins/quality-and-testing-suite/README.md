# Quality & Testing Suite

Suite de aseguramiento de calidad (QA), accesibilidad web y verificación funcional:
- **Playwright CLI:** Automatización de navegador para inspeccionar renderizado real, estados y consola en `http://localhost:4321`.
- **Accesibilidad (a11y):** Cumplimiento con las pautas WCAG 2.2 AA (contraste de color, navegación por teclado, roles ARIA en selects y tablas).
- **TypeScript estricto:** Prevención de regresiones y discrepancias entre `src/types/` y `src/lib/nicholas/`.
